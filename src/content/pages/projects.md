## Low-latency message transport (C++)

A message transport library for IPC, UDP, and reliable UDP, inspired by the LMAX
Disruptor: cache-line aligned data structures, kernel bypass, real-time thread
scheduling, memory pools, and latency profiling. _In progress._

## Tree Evaluation (C++20 / Python)

An implementation of the warm-up version of Cook & Mertz's tree evaluation
algorithm, with a C++20 core and a Python prototype.
[Source on GitHub](https://github.com/ahmedmhedhbii/tree-evaluation)
